# 👗 Fashion Recommendation Web App

A simple Flask-based web application that recommends fashion outfits based on user preferences like gender, weather, and occasion.

## Tech Stack

- **Backend**: Python (Flask)
- **Frontend**: HTML, CSS (Jinja Templates)
- **Database**: MySQL
- **Authentication**: Flask-Login
- **Data Storage**: SQLAlchemy ORM

## Features

- User Signup and Login with secure password hashing
- Personalized outfit recommendations based on:
  - Gender (Male/Female)
  - Weather (Summer/Winter)
  - Occasion (Casual/Formal/Party)
- Rule-based recommendation engine (no AI/ML used)
- User preferences stored in the database
- Simple and clean UI
